# **App Name**: FoodBridge

## Core Features:

- Donor Food Posting: Donor login and form to input food details (type, expiry, quantity, location, photo).
- Pending Donation Display: Display of pending food donations in a column format on the donor's page, showing image and details.
- Receiver Donation Discovery: Receiver login and display of available food donations within a 30km radius.
- Detailed Food Info View: Display detailed information on a separate page when a food donation is selected.
- Food Claiming: Option for receivers to 'take' a food donation, marking it as taken.
- Real-time Status Update: Real-time update of donation status for both donors and receivers after a donation is claimed. Once the user leaves and returns to the page, it should reset.
- AI Food Categorization: AI tool to automatically categorize food type from the uploaded photo using image recognition, and suggest relevant tags.

## Style Guidelines:

- Primary color: Earthy Green (#8FBC8F) to convey nature, health, and food.
- Background color: Light Beige (#F5F5DC) for a warm, inviting, and clean feel.
- Accent color: Muted Orange (#FFA07A) to highlight key actions and information, suggesting warmth and energy.
- Font: 'PT Sans', a humanist sans-serif that combines a modern look and a little warmth or personality; suitable for headlines or body text.
- Use clear, intuitive icons to represent food types, locations, and donation status.
- Clean and organized layout with clear visual hierarchy, prioritizing food information and easy navigation.
- Subtle transitions and animations to provide feedback on user actions, such as claiming a donation or updating the donation status.
